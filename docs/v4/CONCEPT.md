# 概念：一次印刷打样（The Proof Sheet）

## 为什么换这个框

《world.execute(me);》的同人影像几乎都走同一条路：聊天记录滚动、AI 觉醒、赛博故障、粉紫霓虹。这条路上最好的东西已经被做完了，再做一遍只是排队。

这首歌的歌词其实给了另一个更少人用的比喻：**它全程在"制造"自己**——object creation、initialisation、parameters、dimension、circumference、nutrients、antioxidants、existence。它把自己当成一件被印出来的东西：先给参数，再给形状，然后上色，最后套准。

所以这支片子的框不是"AI 在聊天"，而是**一张一张印出来的她**：

> 整部 MV 是一本印刷校样册。每一句歌词是一次印刷。三种油墨是蓝、白、黑。错误是套印不准。

## 视觉签名（可复用的四个元素）

1. **校色条**：每张版画底部四块色（我／你／墨／错误），位置和大小固定，像印厂打样页边的色标。
2. **印张号**：右上角 `SHEET 05/12`，全片十二张，观众能数出"印到第几张了"。
3. **套准十字**：四角细十字 + 圆，比裁切线更轻，压在画面上。
4. **PROOF 章**：右上第二行，小号、灰、不抢。

这四个元素只在**版画**里出现，界面和代码段没有。最后一帧全部消失——那是成品，不是校样。

## 十二张印张与"越印越不准"

| 印张 | 段落 | 状态 |
| --- | --- | --- |
| 01–02 | 开机、标题 | 单色打样，只有轮廓 |
| 03 | 副歌一四张版画 | 干净，三墨齐全 |
| 04 | 主歌二（茄子、番茄、猫、神） | 多一个专色版，套得准 |
| 05 | 导歌二（性别、一天、角色） | 控件放大，开始出现 10px 错版 |
| 06–07 | 副歌二、空线程 | 灰版介入，人物只剩一个版 |
| 08 | 报错段 | 红第一次出现，错版 18px |
| 09 | 最后副歌 | 错版 28px，红边露出来 |
| 10 | LOVE 四句 | 每唱一遍压一次，重影叠上去 |
| 11 | 证明 | 三版在三帧内对准，红消失 |
| 12 | 最后一帧 | 成品：没有校样标记，最亮，静止 |

错版距离（10 / 18 / 28 像素）不是乱给的：它跟着"她还剩几个版"走。副歌一三版齐全，导歌二缺米白，报错段只剩轮廓，最后副歌错到能看见红边——观众不需要被告知，数字会自己说话。

## 六种印刷缺陷（数数段）

`Ein, Dos, Trois, Ne, Fem, Liu` 六张卡，同一句话印六次，六次都不干净：

| 语言 | 缺陷 | 画法 |
| --- | --- | --- |
| de | 套印偏移 | RGB 横向错 3px，边缘露红 |
| es | 飞墨 | 90 个随机墨点溅在下半幅 |
| fr | 网点过重 | 整幅半调网点，越往下越密 |
| ko | 背面透印 | 镜像的暗字从纸背透出来 |
| sv | 撕边 | 上下纸边锯齿轮廓 |
| zh | 墨流 | 亮部提取 + 模糊回叠，数字边缘化开 |

这六种缺陷对应六种"翻不过去的语言"：不是翻译错了，是这一版根本印不出来。

## 与歌词的关系

歌词换成官方版本（85 行，行时间取 LRC 行首），关键词落点仍用实测值。核对过：`To F, to M`（90.34）到 F（90.80）是一拍，到 M（91.72）是三拍；`To S, to M`（97.72）到 S（98.19）、M（99.10）同样对得上。所以时间轴不用改，只换词。

## 一句话

别人拍"她爱你"，这支片子拍"她被印出来，而且没印准"。
